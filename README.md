# HMP To-Do App 📝

Eine einfache Android To-Do-Liste mit integriertem Logo der HMP Profi GmbH[span_1](start_span)[span_1](end_span), entwickelt mit **Jetpack Compose** und Material 3.

## Features ✨
- **To-Dos hinzufügen:** Schnelles Erfassen neuer Aufgaben.
- **Abhaken:** Erledigte Aufgaben per Checkbox durchstreichen.
- **Löschen:** Aufgaben über den Löschen-Button entfernen.
- **Individuelles Logo:** Zeigt das offizielle HMP-Logo direkt in der Top-Leiste[span_2](start_span)[span_2](end_span).

## Technologie 🛠️
- Kotlin
- Jetpack Compose
- Material Design 3
